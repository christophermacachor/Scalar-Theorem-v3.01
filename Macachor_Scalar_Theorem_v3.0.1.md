Theorem I (Macachor Scalar Theorem — Generalized Pythagorean).

Let ρ₁, ρ₂, ..., ρₙ be n orthogonal scalar density components. The total scalar

ρ_total = √3 · ρ₁.

    |q| = √(a² + b² + c² + d²)

    |q'| = |q|

This provides a coherence-preserving transformation group for quantum states.

Proof. Unit quaternion conjugation is an isometry of ℝ⁴. The norm is invariant 
under orthogonal transformations. ∎
